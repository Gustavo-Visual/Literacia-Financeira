# 📚 Enciclopédia de Literacia Financeira

Uma enciclopédia digital interativa dedicada à educação financeira, desenvolvida em português para ajudar utilizadores a compreender conceitos financeiros essenciais.

## 🌐 Demonstração

Visite o site:  [Literacia Financeira](https://gustavo-visual.github.io/Literacia-Financeira/)

## ✨ Funcionalidades

- **Interface Premium** - Design elegante e profissional com navegação intuitiva
- **Conteúdo Educativo** - Informações detalhadas sobre literacia financeira
- **Gráficos Interativos** - Visualizações de dados com Chart.js
- **Design Responsivo** - Adaptado para dispositivos móveis e desktop
- **Navegação por Sidebar** - Menu lateral escuro para fácil acesso ao conteúdo

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **Tailwind CSS** - Framework de estilização
- **Chart.js** - Biblioteca de gráficos
- **Google Fonts** - Tipografia (Plus Jakarta Sans, Playfair Display)

## 🚀 Como Usar

1. Clone o repositório: 
   ```bash
   git clone https://github.com/Gustavo-Visual/Literacia-Financeira.git
   ```

2. Abra o ficheiro `index.html` no seu navegador

Ou simplesmente visite a versão online através do GitHub Pages. 

## 📁 Estrutura do Projeto

```
Literacia-Financeira/
└── index.html    # Página principal da enciclopédia
```
